# Universal Coder 0.3

V0.3 adds persistent run history, interactive approvals, Git integration primitives, independent review support, richer CLI commands, and a more durable agent loop.

## Commands

`coder run "task" --workspace .`

`coder run "task" --review`

`coder run "task" --approve`

`coder history`

The runtime remains provider-neutral and requires no third-party Python dependencies.
