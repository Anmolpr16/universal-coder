# Universal Coder 1.0

V1.0 is the production-core milestone. It adds a hardened HTTP boundary around the existing model-agnostic agent runtime.

## Security boundary

- `CODER_AUTH_TOKEN` authenticates HTTP requests when configured.
- Non-loopback server binds require `CODER_AUTH_TOKEN`.
- HTTP request bodies have a configurable size limit.
- API keys are never accepted from HTTP request bodies; configure provider credentials in the server environment.
- Concurrent runs are bounded by `CODER_MAX_CONCURRENT_RUNS`.
- Health remains available without authentication for liveness checks.

## API

- `GET /health`
- `GET /capabilities`
- `POST /run` returns a run id immediately.
- `GET /runs/<id>` returns current state and persisted record.
- `POST /stream` streams execution events using SSE.

V1 does not claim to be a complete OS-level sandbox or a hosted SaaS security boundary. Run untrusted repositories with an external container/VM sandbox.
