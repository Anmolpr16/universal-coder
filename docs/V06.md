# Universal Coder V0.6 — Autonomous Pipeline

V0.6 connects planning, specialist consultation, isolated parallel implementation, candidate arbitration, safe integration, and final verification into one pipeline.

## Pipeline

1. Build repository context.
2. Decompose the objective into concrete tasks using the configured model, with a deterministic fallback.
3. Consult architect, tester, and reviewer specialists in parallel.
4. Run three implementation candidates in isolated Git worktrees when a committed Git base is available.
5. Ask independent reviewers to score candidate diffs.
6. Select the highest-scoring candidate and apply it with `git apply --check --3way` before mutation.
7. Hand the integrated workspace back to the primary coding agent for completion and repair.
8. Run final project verification.

If worktrees are unavailable, the pipeline safely falls back to direct implementation rather than modifying a non-Git workspace through the parallel subsystem.

## CLI

```bash
coder run "refactor the parser and add regression tests" --autonomous
```

`--autonomous` is intentionally separate from `--parallel`: autonomous mode owns the complete orchestration lifecycle, while parallel mode exposes the lower-level candidate-generation mechanism.

## Safety boundaries

- Candidate agents operate outside the main worktree.
- Candidate integration is checked before application.
- The final agent runs in the real workspace and is still subject to the normal tool permissions.
- Verification is performed after integration.
- No automatic commit or push is performed.
- Public exposure of the HTTP server still requires authentication, TLS, and sandboxing.
